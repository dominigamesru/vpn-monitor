# Спека: мониторинг VPN для админов — Prometheus, Grafana, Zabbix

Статус: **предложение, не реализовано**. Источник — запрос заказчика 2026-11-01. Нужен адрес Prometheus
(Pushgateway или remote write) или Zabbix-сервера — до этого отправка выключена.

## Зачем
Каждое приложение видит только свою машину. Админам нужно видеть всех сразу и отличать «у сотрудника плохой
интернет» от «упал VPN-шлюз или SVN в офисе»: если плохо у многих одновременно — причина в офисе.

## Что отправляет приложение
Раз в проверку (1–3 мин), только цифры и статусы, без секретов и без адресов профилей с ключами. Метки: `user`
(логин AD), `host` (имя компьютера), `client` (клиент VPN), `profile` (безопасное название профиля), `city`,
`version`.

| Метрика | Тип | Что |
|---|---|---|
| `vpnmon_score` | gauge | оценка VPN 1–99 |
| `vpnmon_link_status{link="inet|vpn|svn|office"}` | gauge | 0 — норма, 1 — так себе, 2 — плохо |
| `vpnmon_cause{link=...}` | gauge | 1 у звена, в котором причина |
| `vpnmon_inet_mbps`, `vpnmon_inet_latency_ms` | gauge | интернет (медиана трёх проверок) |
| `vpnmon_vpn_latency_ms` | gauge | средняя задержка до офиса через VPN |
| `vpnmon_svn_mbps` | gauge | средняя скорость SVN |
| `vpnmon_service_up{service="confluence|jira|svn|..."}` | gauge | 1 — отвечает, 0 — нет |
| `vpnmon_service_auth_ok{service=...}` | gauge | вход AD принят |
| `vpnmon_world_up{service="chatgpt|claude|luma"}`, `vpnmon_world_via_vpn` | gauge | мир |
| `vpnmon_vpn_up` | gauge | туннель поднят |
| `vpnmon_check_duration_seconds` | gauge | длительность проверки |

## Транспорт
- **Prometheus:** Pushgateway (`/metrics/job/vpnmon/instance/<host>`) — проще всего за NAT и на ноутбуках; либо
  remote write. Адрес и токен — в `settings.json` (`prometheus.url`), токен — в Диспетчере учётных данных.
- **Zabbix:** trapper-элементы через `zabbix_sender`-протокол (JSON на порт 10051) с ключами `vpnmon.score`,
  `vpnmon.link[vpn]`, …; узел — имя компьютера, шаблон — «Domini VPN Monitor».
- Нет сети — копим последние значения в памяти, при возврате шлём только свежие (историю не досылаем).

## Grafana — дашборд «VPN сотрудников»
1. **Сейчас:** доля сотрудников по цвету (зелёный/жёлтый/красный), карта городов, таблица «кто красный и в чём
   причина».
2. **Офис:** `vpnmon_service_up` по сервисам — сколько сотрудников видят сервис недоступным; если больше
   порога — сервис лежит, а не сеть людей.
3. **VPN-шлюз:** медиана `vpnmon_vpn_latency_ms` и `vpnmon_svn_mbps` по всем, по клиентам и профилям.
4. **Человек:** выбор `user` — его звенья за сутки и неделю (как «История» в окне).

## Алерты
| Алерт | Условие | Кому |
|---|---|---|
| **Офисный сервис недоступен** | `vpnmon_service_up == 0` у ≥ 30% активных за 5 мин | админы офиса |
| **VPN-шлюз деградировал** | медиана `vpnmon_vpn_latency_ms` > 700 мс или `vpnmon_svn_mbps` < 2 у ≥ 30% за 10 мин | сетевики |
| **Массовый «пароль AD не подошёл»** | `vpnmon_service_auth_ok == 0` у ≥ 5 человек за 15 мин | админы AD |
| **Мир закрыт через VPN** | `vpnmon_world_up == 0` при `vpnmon_world_via_vpn == 1` у ≥ 30% | сетевики |
| **Сотрудник давно красный** | `vpnmon_score < 40` дольше 2 ч в рабочее время | поддержка (тикет) |
| **Старые версии** | `count by (version)` — версия старше двух релизов у > 10% | Claude/CI |

Одиночные проблемы людей не алертим — их видит сам сотрудник и шлёт сводку в поддержку.

## Совместимость и приватность
- Отправка выключена по умолчанию; включает `settings.json` (удалённые настройки), сотрудник видит в «Настройках»,
  что и куда уходит.
- Метки без секретов; `profile` — то же безопасное название, что в меню.
