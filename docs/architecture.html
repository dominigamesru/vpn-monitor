VPN Monitor — как устроено

Черновик схемы (до первой версии). Приложение в трее Windows регулярно запускает пробы: скачивает пробные данные с GitLab и SVN офиса через VPN и, для сравнения, из интернета. По итогу красит иконку-светофор и шлёт метрики в Prometheus. Прототип замера — scripts/net_speed.py.

Компоненты

Один цикл

Планировщик: пришло время (или нажали «Проверить сейчас») — запускает пробу, если предыдущая закончилась
Проба: по каждой цели — задержка (DNS, TCP), затем пробное скачивание до N секунд; ошибка — тоже результат
Оценка: сравнивает с порогами → зелёный / жёлтый / красный; иконка и подсказка трея обновляются
Метрики: задержка, скорость и успех по целям уходят в Prometheus
