# Сообщения админов сотрудникам

Как сказать всем, у кого стоит VPN Monitor, «знаем, чиним» — без релиза ([ADR 0014](../adr/0014-admin-announcements.md)).

1. Создайте или поправьте `app/config/announce.json` в `main` (образец — [announce.example.json](announce.example.json)).
   Workflow `announce` проверит файл и положит его в релиз `latest`.
2. Через ≤ 5 минут у всех: плашка сверху меню у иконки и окна (с крестиком, сама не исчезает) и одно уведомление Windows.
3. Решили — допишите в то же сообщение `resolved` (`title`, `text`, по желанию `at`). Кто видел красную плашку, увидит
   вместо неё зелёную «решено» и уведомление; кто не видел — ничего. Зелёная уходит сама через сутки.
4. Убрать всё — удалите файл; `until` — сообщение само перестаёт показываться после этого времени.

| Поле | Что |
|---|---|
| `id` | уникальный; по нему приложение помнит «видел» и «закрыл». Новое сообщение — новый `id` |
| `level` | `info` (синяя), `warn` (жёлтая), `outage` (красная; вместо совета «создайте запрос» — «звонить не нужно, админы знают») |
| `title`, `text` | заголовок и текст — как в чат сотрудникам, коротко |
| `link` | «подробнее», только `https://` |
| `targets` | затронутые сервисы (`svn`, `jira`, `confluence`, `gitlab`) — для совета; показываем всем |
| `until` | ISO 8601 (`2026-11-03T00:00:00+03:00`) — после этого не показывать |
| `resolved` | `{title, text, at}` — ситуация разрешена |
