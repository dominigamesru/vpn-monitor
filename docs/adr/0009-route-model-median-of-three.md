# Оценка VPN — по маршруту «интернет → VPN → офис», статус звена — по медиане трёх проверок

С v0.6 VPN оценивается не долей канала и надбавкой к своей норме (v0.5), а звеньями маршрута с порогами из
`settings.json`: средняя скорость SVN (норма от 8 Мбит/с), средняя задержка до офиса через VPN (до 300 мс), скорость
и задержка интернета. Норма интернета = норма SVN: если интернет медленнее, SVN физически не в норме, и причина —
интернет, а не VPN; так звенья не противоречат друг другу и ухудшение идёт каскадом. Причина — первое звено не в
норме; звенья ниже помечаются «из‑за интернета» / «из‑за VPN». Статус звена — медиана трёх последних проверок:
линейная регрессия по трём точкам выпад в последней проверке не гасит, а усиливает; в истории — каждая проверка как есть.

## Последствия
- Цвет и оценка иконки, меню, окно и история считаются из одной модели (`app/src/route.rs`), тесты — на реальном
  логе заказчика.
- В оценку каждое звено идёт один раз (0.6.0 считала медленный SVN трижды — оценка 1).
- Пороги меняются в `settings.json` без релиза; старые поля оценки (`parts`, `baseline`, доля канала) остаются в API
  для совместимости.
