# Удалённые настройки — `office.json` в релизе `latest`, проверка раз в 5 минут

Пороги, список сервисов и адрес поддержки меняются без релиза: файл `app/config/office.json` в `main` workflow
`office` публикует в релиз `latest`; установленные копии раз в 5 минут скачивают его, накладывают поверх своих
настроек (объекты — рекурсивно, `targets` — по `id`, остальные массивы — целиком), проверяют результат так же, как
`settings.json`, и применяют без перезапуска. Копия лежит в папке установки — для запуска без сети. Файла нет —
копии возвращаются к своим настройкам. Отдельный файл, а не новый `settings.json` релиза: так поменять порог для
всех можно за минуты, без сборки, а откат — удалить файл.

## Последствия
- `office.json` — тоже контракт: только поля, которые понимает старая версия, или новые (их она пропустит);
  ошибка в файле — копии его не применяют и пишут в лог.
- В «Настройках» видно, что пришло из удалённых настроек и когда применено.
- Ошибка сети — запись в лог только при смене ошибки (без сети это было бы раз в 5 минут).
