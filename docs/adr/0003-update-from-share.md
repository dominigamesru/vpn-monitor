# Обновление и настройки — с шары, по CRC32

Сервера обновлений нет и заводить его не хотим: свежий exe и настройки лежат на сетевой шаре офиса, в настройках —
CRC32 exe. Приложение при старте сверяет CRC32 своего exe, при расхождении копирует новый в пользовательское
пространство, переписывает автозапуск и перезапускается. Шара видна только через VPN, поэтому без VPN приложение живёт на
локальной копии настроек. Раскладка шары и формат настроек — контракт со всеми установленными копиями: менять только
с обратной совместимостью.
