# Rust для приложения в трее

Приложение должно быть одним самодостаточным exe для Windows, а потом для macOS и Linux. Рассматривали Go и Rust — оба
дают exe без рантайма; выбор заказчика — Rust. Rust даёт exe меньше и легче по памяти для процесса, который живёт в трее
весь день. Цена — трей (`tray-icon` + цикл событий) и сборка под macOS сложнее, чем в Go, и писать дольше.
