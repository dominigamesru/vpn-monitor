# Сообщения админов — `announce.json` в релизе `latest`, «решено» — в том же сообщении

Админам нужно сказать всем сотрудникам «знаем, чиним» быстрее релиза и так, чтобы при аварии люди не звонили в
поддержку. Решение (заказчик 2026-11-01/02): файл `app/config/announce.json` в репо, workflow `announce` кладёт его в
релиз `latest` (как `office.json`, ADR 0011); приложение проверяет его раз в 5 минут. Новое сообщение — плашка с
крестиком в меню и окне (сама не исчезает) и одно уведомление Windows **всем**. Окончание — секция `resolved` в том же
сообщении: у тех, кто видел красную плашку, она сменяется зелёной «решено» и приходит ещё одно уведомление; кто не
видел — ничего не получает. Зелёная уходит через сутки или по крестику.

## Последствия
- Контракт с установленными копиями: формат `announce.json` (поля только добавляются, незнакомые терпятся, незнакомый
  `level` — как `info`), имя ассета, `user.json` → `announce` (`seen`, `dismissed`, `resolved_seen`).
- Память «видел/закрыл» — на машине сотрудника; новое сообщение — новый `id`.
- Нет сети до GitHub — показываем последнюю скачанную копию (`announce.json` в папке установки).
- Модель — чистая функция `announce::select` с тестами (активное → решено, кто не видел, крестик, `until`).
