# Окно — страница в браузере от локального API, а не нативный интерфейс

Окну нужны графики за сутки и неделю и диагностика подключения; тот же набор данных нужен скриптам и ИИ-агентам
(режим API, R7). Выбрали одно: приложение всегда поднимает HTTP API на `127.0.0.1:5151` (занят — до 5160), а окно —
встроенная в exe страница, которую открывает браузер по двойному клику на иконке или пункту меню. Нативный интерфейс
(egui, WebView2) отвергнут: ещё одна большая зависимость, а API всё равно нужен. Цена: окно живёт в браузере, а не в
своём окне; страница должна быть одним файлом без CDN, потому что открывается именно тогда, когда сеть лежит.

## Последствия
- API доступен только с этой машины; меняющие запросы требуют заголовка `X-VPN-Monitor: 1`, `Host` проверяется —
  чужая страница в браузере не может дёрнуть проверку или автозапуск.
- Флаг `--api` из R7.1 больше не нужен: API включён всегда (только локально).
- История для графиков — файлы метрик (`metrics_1d.json`, `metrics_7d.json`), их формат — тот же контракт, что и для
  Prometheus позже.
