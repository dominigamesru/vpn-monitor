# Меню у иконки — своё окно на WebView2, страница из exe; проверка — в настоящем хозяине

Меню у иконки (v0.5) — окно без рамки с WebView2 (wry) и страницей `/flyout` локального API, а не системный список
строк: так помещаются маршрут, подсказки и иконки. Страница живёт в хозяине, который ведёт себя не как браузер:
wry объявляет `window.ipc` неконфигурируемым свойством (`const ipc` в странице ломал весь скрипт в 0.5.0–0.5.1),
`requestAnimationFrame` в скрытом окне не срабатывает, высоту окна задаёт страница. Поэтому проверка браузером
недостаточна: CI на Windows открывает меню в настоящем WebView2 и ждёт «страница меню на связи» и «нарисована».

## Последствия
- Нет WebView2 — трей работает со старым системным меню.
- Ошибки страницы (включая ошибки разбора) идут в лог приложения отдельным первым скриптом.
- Имитация хозяина в тестах — по исходникам wry; правила — `.claude/rules/web.md`.
