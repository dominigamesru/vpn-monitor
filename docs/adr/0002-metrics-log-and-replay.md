# Метрики: сначала файл, потом Prometheus с досылкой

Prometheus доступен только через VPN, а интереснее всего именно моменты, когда VPN лежит. Поэтому каждая метрика сначала
пишется в локальный файл, а в Prometheus уходит через remote write: приложение помнит время последней успешной
отправки и, когда связь вернулась, досылает пропущенное с исходным временем. Pushgateway отвергнут: он хранит только
последнее значение, и всё, что было без VPN, потерялось бы. Ноутбук за VPN Prometheus опрашивать не может, поэтому
только push.
