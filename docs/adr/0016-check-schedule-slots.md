# Проверки — раз в 15 / 10 минут, у каждого сотрудника своя минута и секунда

Было: раз в 3 минуты при зелёном и раз в минуту при жёлтом и красном, от момента запуска. Сотрудников много, и
утром или после общего сбоя все проверяют офис почти одновременно — это лишняя нагрузка на Confluence, Jira, SVN и
GitLab в самый неудобный момент. Решение (заказчик 2026-11-03, 0.9.8):

- `check_interval_green_sec` = 900, `check_interval_alert_sec` = 600 (`settings.json`, можно поменять через
  `office.json`).
- Сдвиг расписания: минута часа 1–15 (для 15 минут) и 1–10 (для 10), секунда 0–59 — случайно один раз, хранится в
  `user.json` → `slot`. Проверка — в ближайший момент, когда минута часа ≡ сдвигу по модулю интервала и секунда
  совпадает (сдвиг 7 → :07, :22, :37, :52). Не раньше чем через минуту после прошлой проверки. Интервал, который не
  делит час (например, 7 минут из `office.json`), — просто через интервал.
- Не по расписанию — как раньше: первая проверка после запуска, «Проверить», повтор при обрыве (ADR 0015).

- **Лёгкий пинг** (`light_ping_sec`, по умолчанию 120 с; 0 — выключен; меняется через `office.json`): пока офис
  молчит (красное «VPN выключен» / «не пропускает трафик»), между полными проверками — `HEAD` к корню серверов
  светофора без входа и без скачивания (сотни байт, пароль не проверяется). Ответил — полная проверка сразу: зелёный
  возвращается за ~2 минуты, а не за 10. TCP-пинг не годится: у Happ TCP «отвечает» всегда — это свой туннель. При
  жёлтом (медленно) пинг не помогает — скорость видна только по скачиванию.

## Последствия
- Подтверждение «VPN упал» (две проверки подряд) — до 10–25 минут вместо 1–4; медиана трёх проверок охватывает
  30–45 минут. Сотрудник, которому нужно сейчас, жмёт «Проверить».
- Контракт: новое поле `user.json` → `slot` (`green_min`, `alert_min`, `sec`); `/api/state` → `next_check_ms`, `slot`.
  Старые версии поле `slot` игнорируют.
- В скорость оценки идёт только SVN: GitLab (публичный проект `vpn-monitor-public/vpn-monitor-sample`, без входа) —
  своя скорость и доступность у сервиса GitLab, «SVN» не подменяет.
