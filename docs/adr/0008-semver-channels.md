# Semver определяет канал: `X.Y.Z` — стабильный, `X.Y.Z-beta.N` — бета

Канал версии выводится из её номера в `app/Cargo.toml`, а не из отдельного файла (`app/config/channel` удалён в
0.5.4). `0.7.0` — стабильная: тег `v0.7.0`, `latest.version` и в стабильном, и в бета-канале. `0.7.0-beta.1` — бета:
тег `v0.7.0-beta.1`, pre-release, файл `domini-vpn-monitor-beta.exe`, только `latest.version` релиза `beta`.
Тег ставит сам релиз (`gh release create`): пушить теги из сессии нельзя, релиз запускается новой версией в `main`.

## Последствия
- Стабильный `latest.version` — всегда `X.Y.Z`: копии до 0.5.4 не разбирают `-beta` и сломались бы.
- Копии до 0.5.4 на бета-канале бету пропускают и ждут стабильную.
- Откат — workflow `promote` со старой версией и каналом; опубликованный релиз не перезаписывается.
