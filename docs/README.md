## Правила
- Пишем по-русски, словами из глоссария. Новый или спорный термин — сразу в `GLOSSARY.md`.
- Одна тема — один документ; ссылки — относительные. Устаревшее удалять или помечать, а не копить.
- Документ, который читают люди вне репо (страница, отчёт), — HTML с тёмной и светлой темой (как `architecture.html`).
- Временные документы (ревью, планы) помечаются «временный» в первой строке и куда переедут правила.
