## 2026-11-01 — первый релиз приложения в трее (v0.1.2)

1. **Факты.** Перенос из GitLab в GitHub; приложение на Rust (`app/`) и CI/CD (`ci`, `release`, `promote`) — PR #1,
   слит (`daa8207`). Опубликованы релизы `v0.1.2` (exe, `settings.json` с SHA-256, `SHA256SUMS`) и `latest`
   (`latest.version = 0.1.2`). Два прогона на машине заказчика по логу: 0.1.0 → 0.1.1 → 0.1.2, установка поверх
   запущенной копии сработала.
2. **Решения.** Rust вместо Go (выбор заказчика, ADR 0001 — я сначала начал на Go, не прочитав контекст). Поставка —
   GitHub Releases вместо шары, «последняя версия» — файл `latest.version`, сравнение на равенство ради отката
   (ADR 0004). Релиз — при новой версии в `main`, а не по тегу: сессия может пушить только в свою ветку.
   Стабильность — с момента включения VPN; оценка — медиана последних 5 проверок.
3. **Находки.** Happ отдаёт подставной DNS `1.2.3.4`; при переключении VPN бывают проверки без DNS вовсе. Через VPN
   задержка 120–390 мс с выбросами до 1,1 с, SVN 1–4,5 Мбит/с, интернет 11–26 Мбит/с. GitLab-проба отвечает 404
   (нет файла в `devops/vpn-monitor-cli` или прав у токена) — не решено.
4. **Ошибки процесса.** Начал писать код до того, как увидел исходный контекст (C:\ недоступен из облака) — потерян
   круг. Первая формула оценки не учитывала выключенный VPN и выбросы — нашлось только по живому логу; подробный лог
   окупился с первого прогона.
5. **Действия.** Процесс: сначала прочитать репо и пересказать понимание, потом код. Код: GitLab-проба — после ответа
   заказчика; пороги скорости — подтвердить. Доки: обновлены `README.md`, `docs/app.md`, `GLOSSARY.md`
   (Стабильность, Релиз, Настройки, Секреты, Последняя версия), ADR 0004.
