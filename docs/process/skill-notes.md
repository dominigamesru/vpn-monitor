# Заметки к скиллам (temp-документ)

Скиллы напрямую не правим (решение пользователя). Сюда — кандидаты в правки с причиной; пользователь решает,
переносить ли их в `.claude/skills/*`.

| Скилл | Предлагаемая правка | Почему (ретро) |
|---|---|---|
| все | новые папки — `git check-ignore -v <путь>` до коммита | перенесено из прошлого проекта |
