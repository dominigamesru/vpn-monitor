Меню 0.9 — контекст сети без перегруза

Три варианта меню на одних данных. Наведите (или нажмите) на значки — подсказки подробные. В обычный день нового почти не видно; на первый план контекст выходит, только когда он и есть причина или ждёт действия.

Ситуация:

A — значки в звеньях: сеть — значком у «Интернета», прогноз SVN — в подсказке «Офиса», звонок — значком камеры в шапке. B — строка контекста: одна строка из трёх коротких плашек под шапкой (сеть, звонок, SVN). C — только по делу: ничего нового, пока всё в норме; плашка появляется только у того, что не в норме. Сообщение админов во всех вариантах — плашка сверху с крестиком.

Окно → «История» → «Ваши сети» (свёрнуто по умолчанию)

Статистика сети — это история, поэтому она во вкладке «История», а не в «Настройках». Та же таблица уходит в запрос в Jira, а metrics_7d.json — вложением в zip.
