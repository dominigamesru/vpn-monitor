# Как писать скрипты

Правила для всего в `scripts/`. Образцы — [common.py](../scripts/common.py), [console.py](../scripts/console.py),
[check_env.py](../scripts/check_env.py).

## Запуск
- Python 3.11+ в `.venv`, зависимости — `requirements.txt`. Скрипты запускаются из корня репо:
  `python scripts/<имя>.py`.
- Один скрипт — одна задача. Докстринг модуля — что делает, что пишет, примеры запуска (`python scripts/x.py --flag`).
- Аргументы — `argparse`; у каждого флага `help`. Без аргументов скрипт делает самое частое безопасное действие.

## Кодировка и файлы
- Первым — `import common`: он включает UTF-8 в консоли Windows (иначе кириллица превращается в «Ð”Ð²Ðµ»).
- Всё, что может попасть в git, писать через `common.write_text` / `write_json` / `open_text` — UTF-8 и LF
  (`open(..., "w")` на Windows пишет CRLF). JSON — `ensure_ascii=False`, отступ 2, перевод строки в конце.
- Форматирование — по [.editorconfig](../.editorconfig), концы строк — по [.gitattributes](../.gitattributes).
- Пути — от `common.ROOT`, не от текущей папки. Отчёты и временное — в `reports/` (в `.gitignore`); скачанное на время
  замера — во временную папку и удалить в `finally` (в т. ч. read-only файлы).

## Вывод
- Цветной вывод — только через `console.py` (`section`, `ok`, `fail`, `warn`, `info`, `detail`, `status_line`,
  `banner`); ANSI-коды руками не собирать. `NO_COLOR` выключает цвет.
- Длительности для людей — `fmt_duration` («39 мин 9 с»).
- Ошибка, которую чинит человек, — `raise SystemExit("что не так и что сделать")`, без трейсбека. Код возврата: 0 —
  успех, 1 — есть проблемы.

## Настройки и секреты
- Настройки и креды — только из `.env` (`common.ENV`; обязательные — `common.require_env(...)`). Новый ключ — сначала в
  `.env.example` с комментарием «что это и откуда взять» (см. шапку файла).
- Значения секретов (`*_TOKEN`, `*_PASSWORD`) не печатать и не логировать; в тексте ошибок заменять на `***`.
  Вписывает их в `.env` только пользователь (скилл `/setup-env`).
- Переменная окружения с тем же именем главнее `.env` — так их задаёт CI.

## Проверка
- Перед коммитом — скрипт запущен хотя бы раз на живых данных, результат виден в выводе.
- Новые папки — `git check-ignore -v <путь>` до коммита.
- Новая зависимость — в `requirements.txt` и в `check_env.py`, если её надо ставить руками.
