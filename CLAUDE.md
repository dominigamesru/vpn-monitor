# Domini VPN Monitor

Приложение в трее Windows (Rust, [ADR 0001](docs/adr/0001-rust.md)): проверяет Confluence, Jira, SVN, интернет и
сервисы в мире, показывает оценку VPN иконкой и меню у иконки, называет виновника — интернет, VPN или сервис.
Заказчик — `dominigamesru/vpn-monitor` на GitHub; пишет по-русски, отвечаем по-русски. Сотрудникам — [README.md](README.md),
разработчикам — [DEVELOPMENT.md](DEVELOPMENT.md) (где что, сборка, скрипты).

## Как работаем
1. **Понять до кода:** прочитать репо и пересказать заказчику понимание задачи; развилки — вопросом с рекомендацией.
2. **Пользовательская функция — скилл `ux-scenarios`:** сценарии вширь и строка в таблице состояний
   [docs/ux/scenarios.md](docs/ux/scenarios.md), потом экран.
3. **Крупная доработка интерфейса — HTML-прототип с вариантами** в `docs/prototypes/` (в облачной сессии —
   опубликовать Artifact, в VS Code — открыть файл в браузере); код — после выбора заказчика.
4. **Веб — только со скиллом `web-ui`**; скриншоты в светлой и тёмной теме; страницы для WebView2 проверять в
   имитации хозяина ([правила](.claude/rules/web.md)).
5. **Код и тесты:** модель — чистые функции с тестами на реальных данных из лога заказчика.
6. **Выпуск — скилл `release`:** PR, зелёный CI на текущем head, слияние, проверка релиза, отчёт заказчику: что
   вышло, что проверить у себя, что не проверено.
7. **Ретро — скилл `retro`** ([docs/process/retro.md](docs/process/retro.md)) после крупного результата, ~10 попыток подряд,
   нового класса ошибки; журнал — `docs/process/retro-log.md`.

## Правила
- **Ветки:** работа — в feature-ветке и PR. В `main` сливает заказчик; Claude сливает зелёный PR, только когда
  заказчик сказал «выпускай» / «по завершении сразу публикуй» — и только его.
- **Термины** — по [GLOSSARY.md](GLOSSARY.md); новый или спорный термин — сразу туда (скилл `domain-modeling`).
- **ADR — на автомате, в том же PR, что и решение, без отдельной просьбы**, если решение трудно отменить или оно
  удивит без контекста: контракт с установленными копиями (JSON, имена файлов, пути), модель оценки, выбор
  хоста/библиотеки/протокола, процесс поставки. Файл `docs/adr/NNNN-slug.md`, формат — скилл `domain-modeling`.
  Спеки до реализации — `docs/specs/`.
- **Все JSON обратно совместимы** (`settings.json`, `user.json`, `latest.version`, метрики, ответы API, Диспетчер
  учётных данных): поля только добавляются (`#[serde(default)]`), старые не меняют смысл, незнакомые терпятся
  (`#[serde(other)]`, без `deny_unknown_fields`); новое значение старого поля — в новое поле (`auth_kind`).
  Имена файлов в релизе и путь exe — тоже контракт ([правила Rust](.claude/rules/rust.md)).
- **Секреты** (`*_TOKEN`, `*_PASSWORD`, пароль AD) не читать вслух, не логировать, не класть в настройки — репо
  публичное. Вписывает только пользователь; новый ключ — сначала в `.env.example` с «что это и откуда взять».
  Секреты CI — только в secrets GitHub.
- **Доки** — по [docs/README.md](docs/README.md): не пересказывать код, одна тема — один документ, HTML для людей —
  с тёмной и светлой темой. Интерфейс поменялся — `python scripts/screens.py` (CI проверяет галерею).
- **Скрипты** — Python по [docs/scripts-guide.md](docs/scripts-guide.md): `import common` первым, запись —
  `common.write_text`, цвет — `console.py`.
- **Новые папки** — `git check-ignore -v <путь>` до коммита.
- **Скиллы** правим по запросу заказчика или через `docs/process/skill-notes.md` (кандидаты с причиной).

## Поставка
GitHub Releases ([ADR 0004](docs/adr/0004-delivery-github-releases.md)), публикует CI при новой версии в `main`.
Semver: `0.6.0` — стабильная (оба канала), `0.6.0-beta.1` — бета (только бета-канал). Релиз «Domini VPN Monitor
vX.Y.Z»: `domini-vpn-monitor.exe` (бета — `-beta`), `settings.json`, `sha256` и `vpn-monitor.exe` для обновлятелей до
0.5.4; `make_latest: false`, опубликованный не перезаписывается. Последняя версия — `latest.version` в релизе
`latest` (бета — в `beta`); откат — workflow `promote`. Подробно — скилл `release`.

## Скиллы
| Скилл | Когда |
|---|---|
| `ux-scenarios` | до любой пользовательской функции, текста, уведомления |
| `web-ui` | всё, что в браузере: меню у иконки, окно, графики, HTML-доки |
| `release` | выпуск версии, бета, откат |
| `retro` | после выпуска, серии попыток, нового класса ошибки, перед компактом |
| `grilling`, `/grill-with-docs` | допрос плана; с глоссарием и ADR |
| `domain-modeling` | глоссарий и ADR |
| `/setup-env` | окружение скриптов и `.env` |
| `frontend-design` (плагин) | визуальное направление нового экрана; ставится из маркетплейса плагинов Claude |
