# Настройка окружения

## Правила
- **Значения из `.env` не читать вслух, не выводить, не логировать** — проверять только «задано / пусто».
- **Секреты (`*_TOKEN`, `*_PASSWORD`, `*_SECRET`, `*_KEY`) вписывает только пользователь.** Несекретное (логины, пути,
  порты) — вписываешь сам.
- Права администратора — только на установку системного ПО (UAC у пользователя на экране).

## Шаги
1. Python 3.11+ (`python --version`), затем `python -m venv .venv` и `.venv\Scripts\pip install -r requirements.txt`.
2. `.env`: нет — скопировать `.env.example`; есть — дописать недостающие ключи с комментариями, значения не трогать.
   Показать пустые и заглушки (`your_login`, `paste_token_here`, `paste_password_here`).
3. Спросить несекретное одним вопросом (AskUserQuestion): логины, пути, порты из `.env.example`.
4. Секреты — объяснить, где взять (ссылка и права — в комментарии над ключом в `.env.example`), и попросить вставить в
   `.env` самому.
5. Проверка: `.venv\Scripts\python scripts\check_env.py`. Показать таблицу как есть; по каждому ✗ — что поставить и
   откуда (раздел «Что поставить» отчёта).
