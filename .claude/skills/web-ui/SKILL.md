# Веб в VPN Monitor

Правила для всего, что рисуется в браузере: окно приложения (`app/web/index.html`, отдаёт локальный API — ADR 0005),
HTML-документы в `docs/`, будущий отчёт «Контекст машины». Словами — из `GLOSSARY.md`.

## Порядок
0. **Сначала сценарии и состояния — скилл `ux-scenarios`** (`docs/ux/scenarios.md`): экран без строки в таблице
   состояний не делается.
1. **Графики и любые визуализации данных — сначала встроенный скилл `dataviz`** (Skill tool). Его процедура
   обязательна: форма → цвет по роли → проверка палитры → разметка → наведение → доступность → отрисовать и посмотреть.
2. Токены и компоненты — из раздела ниже; новые цвета не придумывать.
3. **Отрисовать и посмотреть:** поднять страницу (для окна — мок API на Python с данными, похожими на реальный лог),
   снять скриншоты Playwright в светлой и тёмной теме, на 1200 и 390 px; смотреть подписи, наложения, переполнение,
   ошибки консоли. Без скриншота работа не сдана.

## Подсказки (тултипы)
- Библиотека — **Tippy.js** (MIT) с Popper: стрелка, своя тема в токенах ниже, анимация `shift-away`, задержка
  показа ~150 мс, на тач-экранах — по нажатию. Файлы библиотеки лежат в `app/web/vendor/` и встраиваются в exe —
  с CDN не грузим (окно должно работать без сети).
- Содержимое подсказки — DOM-элемент, собранный через `textContent` (никогда HTML-строкой из данных): иконка
  статуса, цвет, значение со сравнением с нормой («283 мс, обычно 180»), где уместно — мини-график за час.
- Подсказка дополняет, а не прячет: то же значение доступно без наведения (таблица, подпись).

## Ограничения окна
- Один файл, всё встроено: никаких CDN, шрифтов и библиотек из сети — окно должно работать, когда VPN и интернет
  лежат (ровно тогда оно и нужно).
- Данные из API (имена, ошибки, лог) — только через `textContent` / `createTextNode`, никогда `innerHTML`.
- Меняющие запросы — `POST` с заголовком `X-VPN-Monitor: 1` (иначе API ответит 403).
- Пороги и интервалы не зашивать в страницу — брать из `/api/state` (`thresholds`, `intervals`).
- Ширина 390 px — без горизонтальной прокрутки; поля 16 px.

## Токены (палитра v0.5+ — холодные чернила; светлая / тёмная)
Источник правды — `:root` в `app/web/index.html` и `app/web/flyout.html`; тёплая палитра dataviz читалась как
«нейроконтент» (замечание заказчика) и больше не используется.

| Роль | Светлая | Тёмная |
|---|---|---|
| Страница / поверхность / вторая поверхность | `#eef1f5` / `#ffffff` / `#f3f5f8` | `#0d131b` / `#161f2a` / `#1f2935` |
| Текст / вторичный | `#15202e` / `#5a6b80` | `#e6edf5` / `#8d9db2` |
| Линии / ось | `#e2e7ee` / `#c9d2dd` | `#263342` / `#34445a` |
| Акцент | `#2f5bea` | `#6f93ff` |
| Серии 1–3 | `#2a78d6` `#eb6834` `#1baf7a` | `#3987e5` `#d95926` `#199e70` |
| Статусы: норма / так себе / плохо / нет данных | `#1f9d55` / `#c98a00` / `#d6453d` / `#8b9bb0` | `#3cc274` / `#e8b23a` / `#f0675e` / `#7d8ca0` |

- Тема — три блока: токены на `:root`; `@media (prefers-color-scheme: dark)` под `:root:not([data-theme="light"])`;
  `:root[data-theme="dark"]`. Выбор сотрудника — `user.json` → `theme`.
- Шрифт — `"Segoe UI Variable Text", "Segoe UI", system-ui, sans-serif` (меню — часть Windows); числа — `tabular-nums`.

## Прототип, галерея, хозяин
- Крупная доработка — сначала HTML-прототип с вариантами в `docs/prototypes/` (несколько вариантов рядом на одних
  данных, переключатель ситуаций из таблицы состояний, подсказки) — заказчик выбирает, потом код.
- Перед релизом, который меняет интерфейс, — `python scripts/screens.py` (галерея `docs/screens.html` из
  настоящих страниц) и скриншоты README из неё (скилл `release`).
- Меню у иконки — в WebView2: правила и грабли — `.claude/rules/web.md` (`window.ipc`, высота окна, кеш).

## Как показываем состояние
- Статус — **цвет + иконка + подпись** всегда вместе: ✓ «норма», ! «так себе», ✕ «плохо», – «нет данных». Цвет
  статуса не используется для серий.
- Светофор и оценка VPN — словами глоссария; «VPN не включён» — красный «!».
- Время — общая ось для всех графиков страницы, перекрестье и подсказка синхронны.
- Один график — одна ось. Разные единицы (мс, Мбит/с) — разные графики друг под другом.
- Пороги из настроек — пунктиром с подписью; периоды «VPN не включён» — бледной полосой на всех графиках.
- Инцидент — только «плохо»; «так себе» видно на полосах, но в список инцидентов не попадает.
- Для каждого графика есть табличный способ увидеть те же факты (список инцидентов, подсказка).
